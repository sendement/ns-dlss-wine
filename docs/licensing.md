# Licensing (audit of 2026-09-21)

Not legal advice; a factual inventory of what the development tree contained, where it came from and what its licence allows.

## 0. Decisions taken
- The project is **MIT** (`LICENSE`, 2026-09-21). Everything GPL was taken out of the tree: the KMS capture (copied from gpu-screen-recorder, GPL-3) was deleted, and MAKO (frame generation, MAKO Scaler, LS1) moved into the separate GPL-3.0 module `ns-mako`, which the core only starts as a process and talks to through files (`docs/module-protocol.md`).
- The **lsfg-vk backend was removed** (CC BY-NC-ND 4.0 forbids derivatives and commercial use); the Lossless Scaling frame-generation method is the MAKO backend.
- **Nothing proprietary is redistributed.** The user drops those files into `user_files/` (`user_files/README.md` names the upstream projects only) and `app/userfiles.py`
  checks them and installs them into `runtime/` before a feature starts. Wine-side libraries derived from LGPL/MIT code are built from upstream + our patches (`tools/build_patched_wine_libs.sh`).
- The FidelityFX SDK is not vendored; `tools/fetch_third_party.sh` fetches the headers (and MAKO at a pinned revision).

## 3. Our own code
Written in this project (no upstream license): `track1/*.py`, `upscalers/`, `framegen/` (except bridges above), `postprocess`, `nsmem/`, `plugin_bridge.py`, `hyprplug/src`, `nvcuda_shim/gen.py`, `dlssg_host.cpp`, `vsr_host.cpp`, `fsr3/*.cpp`, tools, tests.
Points to keep in mind: (a) the protocol layouts used to talk to NeuralScreen's worker were learned from reading its source - keep no NeuralScreen code/text in the repo, describe the interface only; (b) `nvcuda_shim` reproduces NVIDIA's internal `cuGetExportTable` integrity check (interoperability work; mention it honestly in the README).

## 4. Consequences for the project license
- Because MAKO-derived (`nsmako_bridge`, `mako_scaler`, `ls1_scaler`) and gsr-derived (`kms/`) files are GPL, the simplest consistent choice is **GPL-3.0** for the whole repository (GPL-3.0-or-later is fine for everything except the gsr-derived files, which are 3.0-only; tag files with SPDX ids). All permissive parts (MIT/BSD/zlib/LGPL-2.1+) are GPL-compatible.
- Alternative: permissive core (MIT/Apache) + the GPL components in separate optional directories (`contrib-gpl/`) with their own license files, loaded only at runtime. Weaker: the combined program still links GPL code at runtime via ctypes.
- "Bring your own binaries": document (never script-download without explicit user action) how a user obtains NVIDIA/NeuralScreen/Merserk/Lossless files. Do not host them, do not link to mirrors of the leaked DLL.

## 5. Repository hygiene (done)
The release tree contains sources only (111 files, ~2 MB): no binaries, no Wine prefix, no third-party clones (`.gitignore`: `runtime/`, `third_party/`, `user_files/*`, build outputs). Files we wrote carry SPDX headers
(GPL-3.0-or-later; MIT for the NIS/FSR1 ports; GPL-3.0-only for the gpu-screen-recorder-derived `app/kms/`). The chronological README became `docs/development-log.md` with absolute paths and download links removed.


## DLSS-G without a third-party bridge (2026-09-21)

`dlssg` now runs on NVIDIA's public NGX API (`hosts/ngxdlssg_host.cpp`, own code, built against the headers of NVIDIA/DLSS which `tools/fetch_third_party.sh`
fetches). The only external file it needs is NVIDIA's `nvngx_dlssg.dll` (shipped in the NVIDIA/DLSS repository; byte-identical to the copy in Visual Enhancer).
Visual Enhancer's `neuroframe_engine_frame_interpolation.dll` is no longer required; it is only used by the legacy `NS_DLSSG_IMPL=bridge` switch.


## RTX VSR without a third-party bridge (2026-09-21)

`rtx_vsr` uses NVIDIA's `nvidia-vfx` Python package natively (`hosts/vsr_native_host.py` in its own venv). The package is proprietary (`LicenseRef-NvidiaProprietary`), is
installed by the user with an explicit command from NVIDIA's own index and is never stored in this repository. The Visual Enhancer bridge and `nvngx_vsr.dll` are only
needed for the legacy Wine host.


## Relicensing to MIT (2026-09-21)
Consequences of the decision above, kept for the record (this supersedes sections 2 (MAKO / gsr rows) and 4):
- Nothing GPL-licensed is in this repository any more; MAKO lives in `ns-mako` (GPL-3.0-or-later, its own repository and `LICENSE`) and gpu-screen-recorder code is gone.
- The core does not import, link or vendor module code. The module interface is a written protocol (`docs/module-protocol.md`) with an MIT reference module (`docs/example-module/`).
  A process boundary with a documented, file-based protocol is the conventional way to keep programs of different licenses separate; this is not legal advice.
- Remaining third-party material is permissively licensed or optional: NIS and FSR 1 ports (MIT, notices kept), the vkd3d-proton patch (LGPL-2.1+, applied by a build script; the patched DLLs are not distributed),
  the dxvk-nvapi patch (MIT), Hyprland headers (BSD-3), NVIDIA NGX headers (compiled against, not redistributed).
- The copyright line in `LICENSE` is a placeholder ("ns-dlss-wine contributors") - set it to the actual holder(s) before publishing.
